# 用户注册与登录功能需求

## 1. 功能描述

用户使用手机号注册账号；注册成功后可使用用户名或手机号 + 密码登录系统。

## 2. 数据字段（注册表单）

### 2.1 用户名 username
- 数据类型：string
- 必填，最小长度 4，最大长度 20 字符
- 同一系统内用户名必须唯一，不可重复注册

### 2.2 密码 password
- 数据类型：string
- 必填，最小长度 8，最大长度 20 字符
- 至少包含字母与数字

### 2.3 手机号 mobile_phone
- 数据类型：phone（11 位中国大陆手机号）
- 必填
- 正则：`^1[3-9]\d{9}$`

### 2.4 验证码 verify_code
- 数据类型：string
- 必填，6 位纯数字
- 正则：`^\d{6}$`，有效期 5 分钟

## 3. 业务规则

### 3.1 登录失败锁定
- 规则名：`lock_after_failures`
- 表达式类型：comparison
- 表达式：`failed_login_count >= 5`
- 期望：连续输错密码 5 次后账号锁定 15 分钟

### 3.2 验证码时效
- 规则名：`code_expired`
- 期望：注册时验证码超过 5 分钟未使用则失效，需重新获取

### 3.3 未注册号码拦截
- 规则名：`unregistered_phone`
- 期望：使用未注册的手机号登录必须被拒绝

## 4. 异常与提示文案

- 用户名或密码错误：提示「用户名或密码错误」
- 连续输错达到上限：提示「账号已被锁定，请 15 分钟后再试」
- 验证码过期：提示「验证码已过期，请重新获取」
- 未注册手机号登录：提示「该手机号尚未注册」
- 验证码格式错误：提示「验证码错误」

## 5. 验收标准

1. 使用正确的用户名和密码可登录成功，进入首页
2. 密码长度边界值 7 位 / 8 位 / 20 位 / 21 位 必须逐一验证
3. 手机号与验证码格式非法必须被前端与后端同时拦截
4. 使用已存在用户名注册时必须提示「该用户名已被注册」
