# 商品搜索功能需求

## 1. 功能描述

用户输入关键词搜索商品，支持排序与分页浏览搜索结果。

## 2. 数据字段

### 2.1 搜索关键词 keyword
- 数据类型：string
- 可为空；搜索框留空时直接浏览全部商品
- 最大长度 50 字符

### 2.2 排序方式 sort_by
- 数据类型：enum
- 默认值：综合
- 枚举值：`综合` / `销量` / `价格升序` / `价格降序`

### 2.3 每页条数 page_size
- 数据类型：int
- 默认 20，最小值 1，最大值 100

## 3. 业务规则

### 3.1 特殊字符处理
- 规则名：`special_chars_safe`
- 期望：关键词包含特殊字符（如 `<>&%`）时按普通字符串处理，不得引发系统错误

### 3.2 空结果处理
- 规则名：`no_result`
- 期望：无匹配商品时提示「未找到相关商品，请调整搜索条件」

### 3.3 空关键词浏览
- 规则名：`browse_all`
- 期望：关键词留空提交搜索时展示全部商品并提示「已展示全部商品」

## 4. 提示文案

- 空结果：「未找到相关商品，请调整搜索条件」
- 空关键词浏览：「已展示全部商品」
- 关键词超长：「关键词长度不能超过 50 个字符」
- 分页超限：「每页最多展示 100 条」

## 5. 验收标准

1. 分页条数边界值 1 / 100 / 101 必须逐一验证
2. 特殊字符搜索不得产生服务端错误
3. 四种排序方式必须逐一验证结果顺序正确
